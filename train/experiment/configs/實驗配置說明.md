# 骨幹網路異質性實驗配置說明

## 📋 實驗概述

已為您設計了一個完整的骨幹網路異質性對比實驗，包含兩個拓樸配置：

### 拓樸A - 核心-邊緣架構
- **檔案**: `backbone_topology_A.json`
- **特徵**: 集中式核心骨幹，高流量集中在核心區域
- **適用場景**: 傳統骨幹網路，核心承載跨區域流量

### 拓樸B - 分散式網狀架構
- **檔案**: `backbone_topology_B.json`
- **特徵**: 分散式區域網狀，高流量分散在邊緣區域
- **適用場景**: 現代分散式網路，邊緣處理本地流量

---

## 🎯 實驗設計重點

### 1. 相同的網路規模
- ✅ **80個節點** (兩個拓樸相同)
- ✅ **200條連結** (兩個拓樸相同)
- ✅ **60個主機** (兩個拓樸相同)
- ✅ **3個區域** (兩個拓樸相同)

### 2. 相同的平均流量
- ✅ **平均利用率**: 30-50% (target_utilization_range: [0.3, 0.5])
- ✅ **流量強度倍數**: 2.5 (flow_intensity_multiplier)
- ✅ **高峰期流量機率**: 80% (peak_flow_probability)
- ✅ **離峰期流量機率**: 40% (offpeak_flow_probability)

### 3. 不同的拓樸形狀

#### 拓樸A結構參數:
```json
"topology_structure": {
  "core_nodes": 20,           // 核心節點數
  "edge_nodes": 60,           // 邊緣節點數
  "core_connectivity": 0.6,   // 核心高度互連
  "edge_to_core_ratio": 0.3,  // 邊緣到核心連接
  "edge_connectivity": 0.15   // 邊緣稀疏連接
}
```

#### 拓樸B結構參數:
```json
"topology_structure": {
  "mesh_density": 0.4,           // 整體網狀密度
  "regional_hubs": 3,            // 區域樞紐數
  "hub_connectivity": 0.5,       // 樞紐連通性
  "inter_regional_links": 15     // 跨區域連結數
}
```

### 4. 不同的流量分佈

#### 拓樸A流量分佈 (核心高流量):
```json
"regional_traffic_distribution": {
  "region_0": {
    "name": "核心骨幹區",
    "traffic_weight": 3.0,        // 🔴 高流量

    "inter_region_probability": 0.7
  },
  "region_1": {
    "name": "東部邊緣區",
    "traffic_weight": 1.0,        // 🟢 低流量

  },
  "region_2": {
    "name": "西部邊緣區",
    "traffic_weight": 1.0,        // 🟢 低流量
    "peak_multiplier": 1.0,
    "inter_region_probability": 0.6
  }
}
```

#### 拓樸B流量分佈 (邊緣高流量):
```json
"regional_traffic_distribution": {
  "region_0": {
    "name": "北部邊緣區",
    "traffic_weight": 2.5,        // 🔴 高流量
    "peak_multiplier": 1.5,
    "inter_region_probability": 0.5
  },
  "region_1": {
    "name": "中央轉接區",
    "traffic_weight": 1.0,        // 🟢 低流量
    "peak_multiplier": 0.8,
    "inter_region_probability": 0.8
  },
  "region_2": {
    "name": "南部邊緣區",
    "traffic_weight": 2.5,        // 🔴 高流量
    "peak_multiplier": 1.5,
    "inter_region_probability": 0.5
  }

```

### 5. 不同的流量高峰時段

#### 拓樸A (核心持續高峰):
- **Region 0 (核心)**: 20-100步 → 長時間高峰
- **Region 1 (東部)**: 0-60步 → 早期高峰
- **Region 2 (西部)**: 120-180步 → 晚期高峰

#### 拓樸B (邊緣輪流高峰):
- **Region 0 (北部)**: 0-70步 → 早期高峰
- **Region 1 (中央)**: 140-200步 → 晚期高峰
- **Region 2 (南部)**: 70-140步 → 中期高峰

## 📊 預期實驗結果

### 拓樸A (核心-邊緣) 預期表現:

**優勢** ✅:
1. **能耗集中管理**: 核心區域的連結可以統一優化
2. **路由效率高**: 跨區域流量經過核心，路徑較短
3. **聚類明確**: 核心和邊緣的聚類邊界清晰

**挑戰** ⚠️:
1. **核心負載高**: 核心節點可能成為瓶頸
2. **邊緣利用率低**: 邊緣連結可能閒置
3. **單點風險**: 核心故障影響大

### 拓樸B (分散式網狀) 預期表現:

**優勢** ✅:
1. **負載均衡**: 流量分散在各區域
2. **容錯能力強**: 多路徑冗餘
3. **區域自主**: 本地流量不經過中央

**挑戰** ⚠️:
1. **整體能耗高**: 更多連結需要維持活躍
2. **路由複雜**: 多路徑選擇增加決策複雜度
3. **聚類不穩定**: 網狀結構可能導致頻繁重新聚類

## 🔍 分析重點

### 比較維度1: 能耗效率
**問題**: 哪種拓樸在相同流量下能耗更低？

**分析方法**:
- 比較總能耗和每流量單位能耗
- 觀察活躍連結數量的變化
- 分析能耗與流量負載的關係

**預期發現**:
- 拓樸A可能在低流量時期能耗更低 (可關閉更多邊緣連結)
- 拓樸B可能在高流量時期表現更好 (負載分散)

### 比較維度2: 延遲性能
**問題**: 哪種拓樸提供更好的延遲保證？

**分析方法**:
- 比較平均延遲和SLA違反率
- 分析不同優先級流量的延遲分佈
- 觀察高峰期的延遲變化

**預期發現**:
- 拓樸A在跨區域流量上可能延遲更低 (經過核心)
- 拓樸B在區域內流量上可能表現更好 (本地處理)

### 比較維度3: 負載平衡
**問題**: 哪種拓樸的負載分佈更均勻？

**分析方法**:
- 計算連結利用率的標準差
- 分析區域間負載差異
- 觀察峰值負載的分佈

**預期發現**:
- 拓樸A可能有較大的負載差異 (核心高，邊緣低)
- 拓樸B可能負載更均勻 (分散式架構)

### 比較維度4: 聚類效果
**問題**: 哪種拓樸更適合動態聚類？

**分析方法**:
- 比較聚類數量的穩定性
- 分析重新聚類的頻率
- 觀察聚類邊界的清晰度

**預期發現**:
- 拓樸A可能聚類更穩定 (結構清晰)
- 拓樸B可能需要更頻繁的重新聚類 (網狀結構)

### 比較維度5: 區域異質性影響
**問題**: 流量異質性如何影響整體性能？

**分析方法**:
- 比較高流量區域和低流量區域的性能差異
- 分析流量模式變化時的適應能力
- 觀察區域間的相互影響

**預期發現**:
- 拓樸A的核心區域性能關鍵 (影響全局)
- 拓樸B的區域獨立性更強 (局部影響)

## ⚙️ 配置參數說明

### 拓樸生成參數
- `seed`: 隨機種子 (A=42, B=123，確保不同拓樸)
- `num_nodes`: 節點數 (80)
- `num_edges`: 連結數 (200)
- `topology_type`: 拓樸類型標記

### 流量參數
- `traffic_load_mode`: 流量模式名稱
- `flow_intensity_multiplier`: 流量強度倍數 (2.5)
- `peak_flow_probability`: 高峰期流量產生機率 (0.8)
- `peak_flow_interval_s`: 高峰期流量間隔 [0.5, 2]秒
- `peak_size_range`: 高峰期流量大小 [8000, 15000] bytes

### 區域參數
- `traffic_weight`: 區域流量權重 (決定流量多寡)
- `peak_multiplier`: 高峰期倍數
- `inter_region_probability`: 跨區域流量機率
- `intra_region_probability`: 區域內流量機率

### 訓練參數
- `episodes`: 訓練回合數 (2000)
- `max_steps_per_episode`: 每回合步數 (200)
- `batch_size`: 批次大小 (64)
- `lr`: 學習率 (0.0003)
