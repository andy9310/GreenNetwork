# 骨幹網路異質性實驗設計

## 實驗概述

本實驗設計用於比較兩種不同骨幹網路拓樸在相同規模但不同流量分佈模式下的性能表現。

## 實驗參數

### 共同參數
- **節點數**: 80個節點
- **連結數**: 200條連結
- **主機數**: 60個主機
- **區域數**: 3個區域
- **平均流量負載**: 40% (target_utilization_range: [0.3, 0.5])
- **訓練回合數**: 2000 episodes
- **每回合步數**: 200 steps

### 拓樸結構差異

#### 拓樸A - 核心-邊緣架構 (Core-Edge)
**檔案**: `backbone_topology_A.json`

**結構特徵**:
- **核心節點**: 20個 (25%)
- **邊緣節點**: 60個 (75%)
- **核心連通性**: 60% (核心節點間高度互連)
- **邊緣到核心比例**: 30%
- **邊緣連通性**: 15% (邊緣節點間稀疏連接)

**流量分佈**:
- **高流量區域**: 核心骨幹區 (region_0)
  - 流量權重: 3.0
  - 高峰倍數: 1.5
  - 跨區域流量: 70%
  - 區域內流量: 30%
  
- **低流量區域**: 東部和西部邊緣區 (region_1, region_2)
  - 流量權重: 1.0
  - 高峰倍數: 1.0
  - 跨區域流量: 60%
  - 區域內流量: 40%

**流量高峰時段**:
- Region 0 (核心): 20-100步 → 持續高流量
- Region 1 (東部): 0-60步 → 早期高峰
- Region 2 (西部): 120-180步 → 晚期高峰

**特性**: 模擬傳統骨幹網路，核心承載大量跨區域流量，邊緣主要處理本地流量。

---

#### 拓樸B - 分散式網狀架構 (Distributed Mesh)
**檔案**: `backbone_topology_B.json`

**結構特徵**:
- **網狀密度**: 40% (整體較均勻的連接)
- **區域樞紐**: 3個區域樞紐
- **樞紐連通性**: 50%
- **跨區域連結**: 15條專用跨區域連結

**流量分佈**:
- **高流量區域**: 北部和南部邊緣區 (region_0, region_2)
  - 流量權重: 2.5
  - 高峰倍數: 1.5
  - 跨區域流量: 50%
  - 區域內流量: 50%
  
- **低流量區域**: 中央轉接區 (region_1)
  - 流量權重: 1.0
  - 高峰倍數: 0.8
  - 跨區域流量: 80%
  - 區域內流量: 20%

**流量高峰時段**:
- Region 0 (北部): 0-70步 → 早期高峰
- Region 1 (中央): 140-200步 → 晚期高峰
- Region 2 (南部): 70-140步 → 中期高峰

**特性**: 模擬現代分散式網路，邊緣區域處理大量本地和跨區域流量，中央主要負責轉接。

## 關鍵差異對比

| 特徵 | 拓樸A (核心-邊緣) | 拓樸B (分散式網狀) |
|------|------------------|-------------------|
| **架構類型** | 集中式 | 分散式 |
| **高流量位置** | 核心區域 | 邊緣區域 |
| **連接模式** | 星狀/樹狀 | 網狀 |
| **流量集中度** | 高度集中 | 分散均勻 |
| **區域內流量** | 低 (30%) | 高 (50%) |
| **跨區域依賴** | 高 (經過核心) | 中 (直接連接) |
| **Seed** | 42 | 123 |

## 實驗目標

### 1. 能耗效率比較
- 核心-邊緣架構在集中式流量下的能耗表現
- 分散式架構在分散流量下的能耗優化能力

### 2. 延遲性能分析
- 不同拓樸結構對平均延遲的影響
- SLA違反率在不同流量模式下的表現

### 3. 負載平衡能力
- 連結利用率分佈的均勻性
- 區域間性能差異

### 4. 動態聚類效果
- 不同拓樸結構對聚類演算法的影響
- 聚類數量和穩定性的變化

### 5. 區域異質性影響
- 高流量區域對整體性能的影響
- 流量模式變化時的適應能力

---

## 使用方法

### 1. 單獨運行拓樸A
```bash
python train.py --config experiment/configs/backbone_topology_A.json
```

### 2. 單獨運行拓樸B
```bash
python train.py --config experiment/configs/backbone_topology_B.json
```

### 3. 批次比較實驗
```bash
python experiment/run_experiments.py --comparison backbone_comparison_config.json
```

## 預期結果分析

### 拓樸A (核心-邊緣) 預期表現:
- ✅ **優勢**: 
  - 核心區域高效能耗管理
  - 集中式控制易於優化
  - 跨區域路由路徑較短
  
- ⚠️ **挑戰**:
  - 核心節點負載過高風險
  - 邊緣節點利用率可能偏低
  - 單點故障影響較大

### 拓樸B (分散式網狀) 預期表現:
- ✅ **優勢**:
  - 負載分散更均勻
  - 區域自主性高
  - 容錯能力強
  
- ⚠️ **挑戰**:
  - 整體能耗可能較高
  - 路由複雜度增加
  - 聚類邊界可能不明確

   - 平均聚類數量
   - 聚類穩定性

## 實驗配置說明

### 流量生成參數
- **流量大小範圍**: 1000-15000 bytes
- **高峰期流量間隔**: 0.5-2秒
- **離峰期流量間隔**: 3-8秒
- **高峰期流量大小**: 8000-15000 bytes
- **離峰期流量大小**: 1000-5000 bytes

### 聚類配置
- **方法**: DP-means adaptive
- **聚類數量範圍**: 3-8
- **Lambda參數**: 2.5
- **重新聚類間隔**: 30步

### 訓練配置
- **演算法**: Double DQN
- **學習率**: 0.0003
- **Batch size**: 64
- **Gamma**: 0.95
- **Epsilon decay**: 5000步

---

## 注意事項

1. **Seed設定**: 兩個拓樸使用不同的seed (42 vs 123) 以確保拓樸結構確實不同
2. **平均流量**: 兩個配置的平均流量負載相同 (40%)，但分佈模式不同
3. **連結容量**: 使用相同的容量分佈 (mean=10.0, std=2.0)
4. **訓練參數**: 除了拓樸和流量分佈外，其他訓練參數保持一致
